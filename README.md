# Elliptic Curve Scalar Multiplication Demo

This project demonstrates how a private key can generate a public key using elliptic-curve scalar multiplication.

Toy Curve:

y² = x³ + 7 (mod 17)

Base Point:

G = (1,5)

Private Key:

k = 6

Public Key:

Q = kG = (5,8)

The demo allows users to step through G, 2G, 3G, ... 6G and visualize the creation of the public key.
